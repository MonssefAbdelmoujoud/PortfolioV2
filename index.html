faq-chatbot

AI-powered FAQ widget · FlagstoneAI-gestuurde FAQ-widget · Flagstone

A floating widget where visitors search frequently asked questions or ask an AI assistant. Plain JavaScript front end; an ASP.NET Core Web API serves the FAQ data from SQL Server and forwards questions to the OpenAI API.

Een zwevende widget waarin bezoekers veelgestelde vragen doorzoeken of een AI-assistent iets vragen. Front-end in pure JavaScript; een ASP.NET Core Web API haalt de FAQ-data uit SQL Server en stuurt vragen door naar de OpenAI API.

  • JavaScript
  • ASP.NET Core
  • EF Core
  • SQL Server
  • OpenAI API

Flagstone wanted a way to bring AI into its services. My mentor gave me the assignment: a widget that's easy to install and cuts the time people need to find important information and analysis, by letting the AI do that work.

To make it easy to install, I published it as an npm package. The AI is connected to the company's database: when a user asks a question, it writes the query itself, looks up the data it needs and answers with that. Its database access is read-only, so it can look things up but never change or delete anything.

Flagstone wilde AI in zijn diensten brengen. Mijn mentor gaf me de opdracht: een widget die makkelijk te installeren is en de tijd verkort die mensen nodig hebben om belangrijke informatie en analyses te vinden, door de AI dat werk te laten doen.

Om het installeren makkelijk te maken, bracht ik hem uit als npm-pakket. De AI is gekoppeld aan de database van het bedrijf: als een gebruiker een vraag stelt, schrijft hij zelf de query, zoekt hij de nodige gegevens op en antwoordt daarmee. Zijn toegang tot de database is alleen-lezen, dus hij kan gegevens opzoeken maar nooit iets wijzigen of verwijderen.

garage-app

in use · v2in gebruik · v2

Phone and PC app for my father's garageApp voor gsm en pc voor de garage van mijn vader

Collects everything the garage needs to invoice a car: details, photos and voice memos, on the phone or the PC. The Android app works fully offline and syncs in the background without duplicating data; a .NET 10 API with PostgreSQL runs in Docker on my home server.

Verzamelt alles wat de garage nodig heeft om een auto te factureren: gegevens, foto's en spraakmemo's, op gsm of pc. De Android-app werkt volledig offline en synchroniseert op de achtergrond zonder dubbele data; een .NET 10-API met PostgreSQL draait in Docker op mijn thuisserver.

  • Kotlin
  • Android
  • .NET 10
  • PostgreSQL
  • Docker

At my father's garage I'm the one who makes the invoices. For every car I need a set of details: mileage, brand, model and so on. My father used to take photos on his phone and send them to me, but that kept causing confusion and miscommunication.

My first version worked completely offline, so everything stayed on my father's phone: to make an invoice, I still had to wait until he came by and handed it to me. So I bought an office desktop and turned it into a home server running Ubuntu Server, with a database and Tailscale for secure access.

Now my father enters a car in the app, it goes to the database, and I pick it up on my PC or phone when I make the invoice, without him having to be around.

In de garage van mijn vader maak ik de facturen. Per auto heb ik een reeks gegevens nodig: kilometerstand, merk, model enzovoort. Mijn vader nam vroeger foto's met zijn gsm en stuurde die door, maar dat zorgde telkens voor verwarring en misverstanden.

Mijn eerste versie werkte volledig offline, dus alles bleef op de gsm van mijn vader staan: om een factuur te maken, moest ik nog altijd wachten tot hij langskwam en me zijn gsm gaf. Dus kocht ik een kantoorcomputer en maakte er een thuisserver van met Ubuntu Server, een database en Tailscale voor veilige toegang.

Nu voert mijn vader een auto in via de app, alles komt in de database terecht en ik haal het op mijn pc of gsm op als ik de factuur maak, zonder dat hij erbij moet zijn.
